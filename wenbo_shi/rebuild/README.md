# Wilson Shi · Personal Frequency 完整网站

这是根据已确认的「自然人像 + 个人频率」方向制作的完整静态网站。旧站与所有原型均保留，当前目录可独立预览。

## 打开方式

直接用浏览器打开 `index.html`。不需要 npm、构建工具、后端或外部 CDN。

也可以在本目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 页面

- `index.html`：个人首页、自然人像、兴趣信号、城市故事、精选项目与旧档案。
- `projects.html`：16 个真实项目，支持类型筛选、关键词搜索和地址栏状态恢复。
- `project.html?id=...`：每个项目的独立详情，包含背景、实际功能、个人贡献、结果、锚点导航、复制链接与前后导航。
- `resume.html`：核心优势、6 条详细项目经历、实习、教育、技能、开源经历与 AI 超级个体荣誉，支持打印 / 保存 PDF。
- `archive.html`：本科摄影、绘画、手作和影像档案，支持筛选与图片放大。
- `contact.html`：无后端联系表单，整理内容后调用访客自己的邮件应用。
- `en/index.html`：完整英文首页；英文项目、简历、档案与联系页也在 `en/` 下，导航可往返切换语言，项目详情保留当前 id。

## 共享功能

- 日间 / 夜间主题与动效偏好本地保存。
- 子页面支持 `Ctrl / Command + K` 命令面板、详情锚点导航、复制链接和返回顶部。
- 项目筛选和搜索状态写入地址栏，支持分享及浏览器前进/后退。
- 首页支持星座连线、照片视差、城市与学校切换及各自代表照片、照片放大。
- 中文与英文独立页面均支持主题、搜索、筛选、简历打印和联系功能。
- 所有页面支持键盘导航、减少动态效果和移动端布局。
- 无手机号、无具体公司名；企业项目均为脱敏口径。

## 内容维护

- 项目内容集中在 `assets/data.js`；英文项目内容集中在 `en/assets/data.js`。
- 全站视觉变量与首页样式位于 `assets/site.css`。
- 子页面样式位于 `assets/pages.css`。
- 全站审查后的可读性、排版与交互增强位于 `assets/refinements.css`。
- 本轮完整优化与复验记录见 `OPTIMIZATION_REPORT.md`。
- 逐页逐按钮的实际交互与导航验证见 `INTERACTION_REPORT.md`（本地与线上合计 924 项次）。
- 主题、动效与命令面板位于 `assets/site.js`。
- 首页交互位于 `assets/home.js`。
- 照片统一放在站内 `assets/img/` 中，避免本地预览时加载上级目录失败；本科照片均明确标为旧档案。
- 外部校园与城市照片的来源、作者与许可证见 `assets/ATTRIBUTION.md`。
