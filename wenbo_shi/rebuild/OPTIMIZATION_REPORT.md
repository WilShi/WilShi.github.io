# 全站优化与复验报告

## 范围

本轮覆盖首页、项目列表、14 个项目详情、完整简历、创作档案和联系页；检查设计、中文排版、内容丰富度、交互与可访问性。旧站和所有原型未改动，未提交或部署。

设计方向保持「自然人像 + 个人频率」：个人经历、开源、电影摄影与城市故事仍是主角，科技感作为辅助，不回退为企业控制台。

## 1. 设计优化

- 保留自然人像、切角照片、轨道和兴趣信号，不增加新的装饰性图标或无意义数据。
- 子页面网格由全强度降为低对比背景，保留识别度但减少正文干扰。
- 日间 accent 调整为 #1f6f47、muted 调整为 #536367，夜间变量保持。
- 修复原生 button 的默认底色，避免夜间简历按钮文字隐形。
- 缩短首页和子页面的无效纵向空间，移动端提前露出人物照片。
- 统一日夜 color-scheme、表单边界和 focus-visible。
- 图片统一在站内 assets/img，避免本地打开时的上级目录加载问题。

## 2. 排版优化

- 标题 letter-spacing 收敛到约 -0.04em，配合 text-wrap: balance / pretty，减少孤字与词语断裂。
- 修复移动项目摘要被挤进编号列的问题；390px 下摘要实际宽度为 310px。
- 联系页移动标题单独控制，避免「从一封邮件开／始」。
- 正文、项目摘要、贡献和简历内容提高到约 14px；标签、页脚与元信息同步提高可读性。
- 关键导航、按钮、信号和链接触控区提升到约 44px；移动导航每项为 44×44px。
- 移动输入框使用 16px 字号，降低 iOS 聚焦自动放大的概率。
- 增加中文 Sans / Serif 回退字体，减少跨平台气质漂移。
- 首页和子页面 section padding 重新收紧，长页面更易浏览。

## 3. 内容与事实优化

- 统一最新身份：算法工程师 · 公司智能体平台负责人；英文为 Algorithm Engineer · Agent Platform Lead。
- 首页 Hero、关于区、项目角色、简历和 SEO 已同步；其他项目仍保留各自项目级角色。
- 简历新增职业摘要与 3 个代表开源仓库直接链接。
- 城市线补充「加拿大中学」前章，连接海外约十年的经历。
- 项目列表生成 14 行静态摘要；关闭 JavaScript 时仍能阅读基本信息。
- 删除或改写重复的「不是演示」「不是凑数量」等防御性表达。
- 企业桌面工作台改回「独立交付」，避免扩大为未经确认的「独立架构设计」。
- 内部连接器描述收紧为公司现有模型、搜索与业务服务。
- 核实 GitHub：dsh-feishu、dsh-ssh-workspace、dsh-external-api、dsh-skill-station、ScholarMind_MAS 的许可证与官方描述，相关内容保留事实依据。
- 未添加正在求职、可到岗时间、未公开荣誉或新虚构数据。

## 4. 用户交互与可访问性优化

- 命令面板支持 ↑ / ↓ / Home / End / Enter / Esc，补齐 combobox、listbox、option、aria-activedescendant、aria-controls 与 aria-live。
- 联系表单 trim 后才校验，纯空格不会生成空邮件；非法邮箱会被阻止。
- 联系页新增复制邮箱地址、复制整封邮件内容；无邮件应用时也有可继续操作的路径。
- 动效关闭后同时停止平滑滚动、CSS 动画与 Canvas rAF；系统减少动态设置变化不会覆盖用户显式保存的 off。
- 主题按钮改为动作型 aria-label，不再读作「日间，已按下」。
- 首页正常打印与「打印简历」分流：正常主页 dialog=none，简历打印 main=none / dialog=block。
- 简历头部邮箱与 GitHub 链接触控高度提升到 44px。
- 项目与详情页补充无 JavaScript 提示。
- 保留城市 tabs 左右键、弹层 Esc、焦点恢复、skip link 和 reduced-motion。

## 5. 最终复验

- 320 / 390 / 768 / 1440 / 1920px：全部页面无横向溢出。
- 320 / 390px：自动检查到的小触控目标为 0。
- 日夜主题：无 JavaScript 错误、无真实破图、无外部资源依赖。
- 日间对比度：accent/paper 5.1878、accent/panel 4.6880、muted/paper 5.3034、muted/panel 4.7925，均 ≥ 4.5。
- 项目筛选 14 → 4 → 10，14 个详情页均可访问，非法 id 有回退路径。
- 命令面板方向键与 Enter 可进入目标项目，空结果有提示。
- 表单空格、有效邮件、邮箱复制和邮件内容复制均通过。
- 首页与简历打印分流通过；简历生成 2 页 A4 PDF，约 464 KB。
- UX 独立复核：未发现遗留 S1 / S2；本轮 S3 可选项也已闭环。
